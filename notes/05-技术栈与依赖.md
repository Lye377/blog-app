# 五、本项目技术栈与依赖

> 学习笔记分册 · 返回 [总目录](../学习笔记.md)

## 技术选型

| 层 | 选什么 | 理由 |
|---|---|---|
| 运行时 | Node.js | 前后端一种语言，降低学习成本 |
| 框架 | Express | 最轻量的 Node.js Web 框架 |
| 模板 | EJS | 接近纯 HTML，嵌入极少量 JS 即可 |
| 数据库 | SQLite | 零安装，就是一个文件 |
| 部署 | 待定（阿里云学生试用） | 6.21 ddl |

## 依赖包一览

| 包 | 分类 | 做什么 |
|----|------|--------|
| express | 框架 | URL 路由 + 请求/响应处理 |
| ejs | 模板 | HTML 里嵌入 JS 动态渲染 |
| sqlite3 | 数据库 | Node.js 读写 SQLite |
| bcryptjs | 安全 | 密码哈希，不可逆存储 |
| express-session | 鉴权 | 登录状态保持 |
| connect-sqlite3 | 存储 | Session 持久化到数据库 |
| express-rate-limit | 安全 | 接口限流，防刷爆 API 额度 / 服务器 |
| nodemon | 开发 | 文件变动自动重启服务 |

> Chart.js（数据可视化）走 CDN 引入，不进 `package.json`；DeepSeek 的默认 Key 走环境变量 `DEEPSEEK_API_KEY`，启动前 `export` 即可，不写进代码。
