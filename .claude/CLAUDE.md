# blog-app 项目规范

## 学习笔记规则

- 每 10 轮对话更新一次 `学习笔记.md`。
- 学习笔记按主题分类（环境与工具、前端、后端、部署、项目技术栈等），新增内容插入对应主题下，不能无序追加。
- 每次更新记录日期和变更摘要。

## 沟通方式

- 默认教学指导模式：解释每一步在干什么、为什么这样，让用户自己执行。
- 用户明确说"直接帮我做"时切换到代劳模式。
- 代码改动完成后，额外解释增减内容的作用。

## 项目信息

- 这是一个 xlab 教学验收项目，从零搭建的个人博客。
- 技术栈：Node.js / Express / EJS / SQLite / bcryptjs。
- mentor 通过 GitHub 仓库验收。
